# Python Web - Django Basics

Welcome to my repository for the **Django Basics** course, part of the **Software Engineer with Python** learning path at **SoftUni** (Software University).
This repository contains all my code, lecture examples, lab exercises, workshops, and notes created during the course.

---

## Course Overview

The **Django Basics** course provides hands-on experience with web development using the **Django Web Framework**. It covers core principles such as the MVT (Model-View-Template) architectural pattern, routing, database management with Django ORM, form handling, and class-based views.
